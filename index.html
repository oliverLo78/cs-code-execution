JavaScript Call Stack – Basketball Example

Call stack snapshots for the code using Basketball, shootThree, and makeShot.

Open the Console

            // Global scope
            const Basketball = 'he shoots';

            const shootThree = score => {

              const makeShot = swish => {
                console.log(`The game was exciting ${Basketball}, ${score}`);
              }

              makeShot(shootThree);
            }

            if (confirm("Do you want to play basketball?")) {
              shootThree(3);
            }

📌 Execution Context Diagram (Step-By-Step)

1) Variable: Basketball
Stored in the Global Execution Context (GEC) because it is declared at the top level.
2) Function: shootThree
Also stored in the Global Execution Context.
3) Running the if(confirm(...)) line
• confirm() is handled by the browser (Web API).
• When the user clicks OK, JavaScript continues and calls shootThree(3).
4) Calling shootThree(3)
A new function execution context is created.
The parameter score receives the value 3.
5) Inside shootThree: declaring makeShot
makeShot is stored inside the execution context of shootThree.
6) Calling makeShot(shootThree)
A new execution context is created for makeShot.
The parameter swish is assigned the function shootThree.

Inside makeShot, JavaScript looks outward through scopes:
• Grabs Basketball from Global
• Grabs score from shootThree’s context
Then runs console.log(...) using those values.
